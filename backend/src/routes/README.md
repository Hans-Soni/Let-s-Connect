# Routes

This directory defines the API endpoints for the application and routes them to their corresponding controller functions.

## Files

- `auth.route.js`: Defines endpoints for user authentication (`/signup`, `/login`, `/logout`) and profile management (`/update-profile`, `/check`).
- `message.route.js`: Defines endpoints for fetching users and messages, and sending new messages (`/users`, `/:id`, `/send/:id`).
