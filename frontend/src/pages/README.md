# Pages

This directory contains the main route components of the application. Each file here typically corresponds to a specific URL route.

## Files

- `ChatPage.jsx`: The main interface where active chats, contacts list, search, and conversations are displayed.
- `LoginPage.jsx`: Component for handling user login.
- `SignUpPage.jsx`: Component for handling new user registration.
- `UserProfilePage.jsx`: Component for managing user profile details, privacy, security, and consent.
- `WelcomePage.jsx`: High-converting landing page highlighting features, WebRTC, ephemeral privacy, and member feedback.
- `NotFoundPage.jsx`: Responsive 404 error page matching the Samvād aesthetic with helpful recovery actions and theme support.
