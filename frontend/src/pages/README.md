# Pages

This directory contains the main route components of the application. Each file here typically corresponds to a specific URL route.

## Files

- `ChatPage.jsx`: The main interface where the active chat sessions are displayed.
- `LoginPage.jsx` / `SignInPage.jsx`: Components for handling user login.
- `SignUpPage.jsx`: Component for handling new user registration.
- `ProfilePage.jsx`: Component for viewing and editing the user's profile.
- `SettingsPages.jsx`: Component for adjusting application settings.
- `HomePage.jsx`: A placeholder or landing page component.
