# Components

This directory contains reusable React components that make up the user interface of the application.

## Active Components

- **`CallModal.jsx`**: Handles WebRTC incoming and outgoing real-time audio/video calls with ringtones, connection status, and mute/camera controls.
- **`TermsContent.jsx`**: Reusable terms of service, privacy policy, and ephemeral 24-hour message retention wording displayed across auth modals and profile settings.
- **`BorderAnimatedContainer.jsx`**: A stylized container component used on profile and authentication pages to provide a smooth animated border effect.
- **`GlobalThemeToggle.jsx`**: Fixed theme switch control for toggling between dark and light modes.
- **`NotificationToast.jsx`**: Custom interactive toast notifications displaying avatars and preview snippets for incoming messages.
- **`PageLoader.jsx`**: Full-page loader spinner for initial authentication verification and async transitions.
- **`DeveloperFooter.jsx`**: Compact footer component presenting developer information and legal copyright.
