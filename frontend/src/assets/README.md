# Frontend Assets Directory (`frontend/src/assets`)

**Brand logos, vector emblems, and static graphic assets bundled by Vite.**

---

## 🌟 Overview

The `frontend/src/assets/` directory houses visual identity assets imported directly into React components. Unlike files in `public/`, these assets are processed, hashed, and optimized by Vite's Rollup pipeline during production builds.

---

## 📂 File Directory & Complete Details

* **`samvaad_logo_dark.png`** — Official high-resolution horizontal logo optimized for dark mode interfaces with silver/white Devanagari typography (`Samवाद`).
* **`samvaad_logo_light.png`** — Official high-resolution horizontal logo optimized for light mode interfaces with obsidian/charcoal typography.
* **`emblem_gold-sNN9olCf.png`** — Royal golden seal emblem of Samवाद, displayed in light theme headers, hero sections, and welcome showcases.
* **`emblem_silver-CXs3LN2i.png`** — Regal silver seal emblem of Samवाद, displayed in dark theme headers, modals, and as the master source for app icons.
* **`favicon.png`** — Tab icon source graphic.
