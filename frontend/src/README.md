# Frontend Source (`src`)

This is the main codebase for the React application.

## Directory Structure

- **`components/`**: Reusable UI components used across different pages.
- **`componentss/`**: (Appears to be a duplicate or temporary directory for components).
- **`hooks/`**: Custom React hooks.
- **`lib/`**: External library configurations (e.g., Axios instance).
- **`pages/`**: Top-level page components corresponding to different routes (e.g., Home, Login, Signup).
- **`store/`**: Global state management configuration using Zustand.

## Key Files

- `main.jsx`: The entry point for rendering the React application into the DOM.
- `App.jsx`: The root component that sets up routing, themes, and global layout.
- `App.css` / `index.css`: Global styles.
