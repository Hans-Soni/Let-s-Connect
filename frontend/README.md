## 🌟 Overview
This directory contains the **frontend** architecture for Let's Connect. It is a single-page application (SPA) built with React and Vite, focusing heavily on performance, modern UI/UX design, and seamless real-time interactions. 

The design system is heavily powered by Tailwind CSS and DaisyUI, which provides out-of-the-box support for beautiful light and dark modes.

---

## 📂 Folder Structure

- **`src/`** - The core source code for the application.
  - **`assets/`** - Static assets like logos, images, and fonts.
  - **`components/`** - Reusable React components (buttons, input fields, containers, chat bubbles, etc.) used across multiple pages.
  - **`hooks/`** - Custom React hooks for specialized logic (e.g., custom media queries, socket listeners).
  - **`pages/`** - Top-level route components (e.g., `HomePage.jsx`, `LoginPage.jsx`, `SignUpPage.jsx`, `ChatPage.jsx`).
  - **`store/`** - State management logic using Zustand. This includes global states for authentication (`useAuthStore`), themes (`useThemeStore`), and chat messages.
  - **`lib/`** - Utility libraries, constants, and helper functions (e.g., Axios configurations for API requests).

- **`public/`** - Publicly accessible static files that bypass the Vite compilation pipeline (includes the `app.zip` mobile installer).
- **`dist/`** - The production-ready build output folder generated by Vite when deploying.

---

## 🛠️ Key Technologies

- **React & Vite:** Fast development and optimized production builds.
- **Tailwind CSS & DaisyUI:** Utility-first CSS framework combined with pre-designed, themeable components.
- **Zustand:** A small, fast, and scalable bearbones state-management solution used for handling user sessions and themes.
- **Socket.io-Client:** Listens and emits real-time events to the backend for instant messaging.
- **Lucide React:** Beautiful, consistent, and scalable SVG icons.
- **React Router:** Declarative routing for seamless page navigation.

## 🚀 Development Setup

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```
*(Note: To deploy to GitHub Pages, you can use `npm run deploy` which automatically builds and pushes the `dist/` folder.)*
