# Frontend

This folder contains the React frontend application for Let's Connect, built using Vite.

## Directory Structure

- **`src/`**: Contains the source code of the application (components, pages, state management).
- **`public/`**: Static assets that are copied directly to the build folder without being processed by Vite.
- **`dist/`**: The production build output directory.

## Key Files

- `index.html`: The main HTML template for the SPA (Single Page Application).
- `vite.config.js`: Configuration for the Vite bundler.
- `package.json`: Contains frontend dependencies (React, Zustand, Tailwind CSS, etc.) and run scripts.
- `tailwind.config.js` & `postcss.config.js`: Styling configuration for Tailwind CSS.
