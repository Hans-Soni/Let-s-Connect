## 🌟 Overview

The `frontend/` directory contains the complete client-side application for **Samवाद**. Built on React 19 and Vite 7, it operates seamlessly as:
1. **A Progressive Web App (PWA):** Installs with 1 click directly onto phone home screens (Android, iOS) and laptops (Windows, macOS) in borderless standalone mode without browser URL bars.
2. **A Native Android App:** Wrapped with Capacitor 8, leveraging native Android hardware permissions for camera, microphone, and audio routing.
3. **A High-Performance Web Client:** Deployed to GitHub Pages using HashRouter for complete URL stability across static asset hosts and mobile WebViews.

## 📂 Subdirectory Navigation & Module Map

| Directory | Purpose & Contents |
| :--- | :--- |
| **`public/`** | Static assets served directly at root: `manifest.webmanifest`, `sw.js` (Service Worker), `sitemap.xml`, `robots.txt`, square high-DPI app icons, and notification sounds. |
| **`src/`** | Core React application source code: `main.jsx`, `App.jsx`, and global CSS stylesheets. |
| **`src/assets/`** | High-resolution branding assets: Samवाद dark/light logos, gold/silver royal emblems, and favicon. |
| **`src/components/`** | Reusable UI components: `CallModal` (WebRTC overlay), `InstallAppBanner` (1-click install sheet), `GlobalThemeToggle`, `PageLoader`, `TermsContent`. |
| **`src/hooks/`** | Custom React hooks for media queries and browser interactions. |
| **`src/lib/`** | Client libraries: `axios.js` (HTTP client with silent refresh), `callSounds.js` (Web Audio API ringtone synthesizer), `terms.js`. |
| **`src/pages/`** | Top-level view routes: `WelcomePage.jsx`, `ChatPage.jsx`, `LoginPage.jsx`, `SignUpPage.jsx`, `UserProfilePage.jsx`, `NotFoundPage.jsx`. |
| **`src/store/`** | Zustand state stores: `useAuthStore`, `useChatStore`, `useCallStore`, `useThemeStore`. |
| **`android/`** | Native Android project generated by Capacitor CLI with Gradle wrapper, manifests, and activity files. |

## 📄 Key Root Configuration Files

* **`package.json`** — Declares dependencies (React 19, Lucide, Zustand, Socket.io-client, Capacitor) and npm scripts:
  - `npm run dev` — Starts local Vite development server on `http://localhost:5173`.
  - `npm run build` — Compiles optimized production bundle into `dist/`.
  - `npm run cap:sync` — Copies compiled web assets to `android/` and updates native plugins.
  - `npm run cap:open` — Launches Android Studio with the project ready to build the APK.
  - `npm run deploy` — Compiles and publishes the application directly to GitHub Pages.
* **`vite.config.js`** — Vite build configuration. Uses `base: './'` to guarantee asset path resolution across both mobile Android WebViews (`http://localhost/`) and GitHub Pages (`https://hans-soni.github.io/Let-s-Connect/`).
* **`capacitor.config.json`** — Configures mobile app ID (`com.hans.samvaad`), app name (`Samवाद`), web directory (`dist`), cleartext network traffic, and keyboard body resizing.
* **`index.html`** — HTML entry point configured with PWA manifest link, square icon declarations (`192x192`, `512x512`), viewport-fit=cover, and theme metadata.

npm run deploy
